# AI 사용량 모니터

이 PC에서 돌아가는 **Claude**(데스크톱 앱·Claude Code)와 **Codex**(데스크톱 앱·CLI)의
작업 상태와 남은 사용량을 한 화면에서 보여 주는 Windows 트레이 앱입니다.
카드 옆에서는 두 캐릭터(클짱·짚짱)가 상태에 따라 움직입니다.

실행 파일: `publish\AIUsageMonitor.exe` (.NET 10 데스크톱 런타임 필요 — 이미 설치되어 있음)

## 보여 주는 것

| | Claude | Codex |
|---|---|---|
| 앱 실행 여부 | `claude.exe` 프로세스 | Store판 `ChatGPT.exe`(OpenAI.Codex) / 직접 설치판 `Codex.exe` |
| 세션·스레드 상태 | `~/.claude/sessions/<pid>.json` + claude.ai 앱 대화·프로젝트 스레드 (작업 중 / 입력·승인 대기 / 완료) | `~/.codex/sessions/**/rollout-*.jsonl` 의 `task_started`/`task_complete` |
| 사용률 | Claude 데스크톱의 기존 로그인으로 사용량 화면과 같은 데이터 자동 조회 | `codex app-server` 의 `account/rateLimits/read` (+ 로그의 `rate_limits`) |
| 기타 | 플랜(Max 5x/20x) | 플랜(Pro 5x/20x), 크레딧 잔액, 무료 리셋권 |
| 세션 클릭 | Claude 앱에서 그 세션·대화 열기 (`claude://`) | Codex 앱에서 그 스레드 열기 (`codex://threads/…`, Store판으로 연결) |

- 메인 화면은 **왼쪽 계정 사용량 / 오른쪽 세션 목록** 순서입니다. 서비스별로 주 계정과 두 서브 계정의 원형 그래프를 세로로 배치하고, 로그인하지 않은 서브 칸은 비워 둡니다. 캐릭터와 말풍선은 세션 영역의 오른쪽 아래에 겹쳐 표시하며, 뒤쪽 목록은 그대로 클릭하거나 스크롤할 수 있습니다.
- 계정 아이디는 **대문자·굵은 글씨**로 표시하고, 바로 아래에 한도 이름을 배치합니다. 남은 퍼센트는 원 가운데에, 리셋 타이머는 원 아래에 `5D 12H 24M` 형식으로 표시합니다.
- 창과 폰트·그래프·캐릭터는 기존 화면의 최대 1.5배로 확대합니다. 시작할 때 화면 높이가 부족하면 내부 요소의 비율을 유지해 높이를 맞추고, 넓어진 가로 공간은 세션 목록에 사용합니다. 실행 중에는 모니터를 옮기거나 창을 복원해도 앱이 크기나 확대 배율을 다시 계산하지 않습니다.
- 계정별로 평소엔 **주간 한도**, 5시간 잔여량이 **10% 이하**이면 그 자리에 **5시간 한도**를 표시합니다. Fable 한도는 화면·트레이·사용량 알림·캐릭터 반응에서 제외합니다.
- 서브 계정 조회가 실패하면 마지막 수치를 흐리게 유지하고 계정명 옆에 경고 표시를 붙입니다. 도움말에서 마지막 확인 시각과 오류를 볼 수 있으며, 조회가 성공하면 정상 표시로 돌아옵니다.
- 리셋 시각만 지나고 새 값이 도착하지 않은 한도는 회색 원과 `확인 중`으로 표시합니다. 이때 100%로 초기화하거나 리셋 축하 연출을 하지 않습니다. 만료된 5시간 한도 대신 유효한 주간 한도가 있으면 주간 한도를 표시합니다.
- 원의 길이는 남은 비율이며, 색은 잔여량에 따라 녹색에서 노란색, 빨간색으로 부드럽게 변합니다. 원에 마우스를 올리면 플랜·리셋 시간·연결 상태를 확인할 수 있습니다.
- 세션 목록은 최소 세 개 이상을 한 번에 볼 수 있는 높이이며, 세션이 많아지면 카드 안 목록만 스크롤됩니다.
- Codex 스레드 상태는 실제 작업 이벤트 시각으로 판단합니다. Codex 앱이 켜질 때 모든 스레드 로그에 덧붙이는
  `thread_settings_applied` 는 활동으로 치지 않습니다.
- Windows에서 열린 로그의 파일 수정 시각이 늦게 갱신되더라도, 늘어난 내용을 읽어 현재 작업 중인 대화를 표시합니다. 처음에는 로그 끝부분을 읽고 이후에는 바뀐 파일만 증분으로 읽습니다.
- Codex의 `session_meta.source.subagent`로 구분되는 자식 에이전트는 목록에서 제외합니다. 해당 로그의 계정 사용량은 계속 집계하며, 일반 대화와 사용자 분기 대화는 유지합니다. Claude 프로젝트의 연결된 실행 세션은 부모 작업의 상태 판단에만 사용합니다.
- 기본 갱신 주기는 로컬 파일 1초, Codex·Claude 사용량 60초입니다.
  claude.ai 앱 대화 목록은 사용량과 함께 읽고, Claude 앱이 켜져 있거나 진행 중인 대화가 있으면 15초마다 따로 확인합니다. 기존 설정 파일에 지정된 서버 조회 주기는 유지됩니다.

## Claude 앱 대화 표시

Claude 카드의 세션 목록에는 이 PC의 Claude Code 세션과 함께 **Claude 앱(claude.ai)에서 진행 중이거나 최근 12시간 안에 활동한 대화**가
"앱 대화" 또는 "프로젝트 작업"으로 표시됩니다. 앱에서 보내는 대화는 대부분 Anthropic 클라우드에서 실행되어 이 PC에 프로세스나 세션 파일이 없기 때문에,
Claude 데스크톱의 기존 로그인으로 사이드바와 같은 대화 목록을 읽어 상태를 판단합니다. 모니터에서 다시 로그인할 필요가 없습니다.

- 일반 대화 목록과 참여 중인 프로젝트의 스레드 목록을 함께 조회합니다. 제목, 프로젝트 이름, 활동 시각, 진행 상태, 열기용 ID만 표시 데이터로 넘깁니다. 서버 응답에 포함된 본문은 표시하거나 저장하지 않습니다.
- 프로젝트 스레드는 `thread_status`의 `working` / `needs_input` / `resolved` / `failed` / `idle`을 각각 작업 중 / 입력 대기 / 완료 / 실패 / 대기로 표시합니다. 보관된 프로젝트·스레드는 제외합니다.
- 프로젝트가 PC에 넘긴 작업은 스레드 메시지의 연결 세션도 확인합니다. 클라우드 스레드가 대기 중이어도 연결된 PC 세션이 실행 중이면 **작업 중**, 승인이 필요하면 **입력 대기**로 표시하며 부제에 **PC 실행**을 붙입니다. 종료되거나 연결이 끊긴 PC 세션을 작업 중으로 세지 않습니다.
- 진행 중(답변 생성·작업 중)이면 "작업 중", 입력이나 승인을 기다리면 "입력 대기"/"승인 대기", 끝났으면 "완료"입니다.
- 조회 실패 시 안내를 표시하고 이전 목록의 진행 중 표시를 "갱신 안 됨"으로 바꿉니다. 마지막 성공 조회가 10분을 넘어도 동일하게 처리합니다.
- 같은 세션이 로컬 세션 파일에도 있으면 로컬 쪽만 보여 줍니다.
- 대화를 누르면 Claude 앱에서 그 대화(`claude://claude.ai/chat/…`) 또는 프로젝트 작업 세션(`claude://claude.ai/cowork/…`)을 엽니다.
- 15초 간격으로 확인하는 동안에는 WebView2를 닫지 않고 유지합니다(Claude 앱을 끄면 다시 조회 뒤 닫음).
- 설정 파일(`settings.json`)의 `ClaudeChatPollSeconds`(기본 15), `ClaudeChatActiveHours`(기본 12)로 조절할 수 있습니다.
- claude.ai 공개 API가 아니라 웹 화면이 쓰는 내부 데이터라서, claude.ai가 바뀌면 동작하지 않을 수 있습니다.
- 트레이 아이콘의 두 막대(왼쪽 Claude, 오른쪽 Codex)는 가장 많이 쓴 한도의 사용률입니다.
- 사용률이 80%·95%를 넘으면 알림을 띄웁니다(리셋 주기마다 한 번).

## Claude 사용량 보기

기본값은 **Claude 데스크톱 로그인 자동 연결**입니다. Claude 데스크톱에 로그인해 두면 모니터에서 추가 로그인 없이
같은 계정의 5시간·주간·모델별 사용량과 재설정 시간을 읽습니다. Codex도 기존 앱/CLI 인증을 그대로 사용합니다.

- `%APPDATA%\Claude`의 로그인 저장소를 읽기 전용으로 열고, 현재 Windows 사용자에게 허용된 Claude 인증만 읽습니다.
- 인증은 숨겨진 InPrivate WebView에서 사용하며, 인증값을 설정·로그·소스에 기록하지 않습니다. 앱 설치 파일은 변경하지 않습니다.
- 데스크톱의 계정 변경·로그아웃은 다음 조회 때 반영되며 이전 계정의 사용량과 앱 대화 목록을 지웁니다.
- 사용량 출처는 계정 그래프의 도움말에서 확인할 수 있습니다. 이 연결은 데스크톱 화면을 캡처하는 방식이 아니라
  동일한 인증으로 서버 데이터를 조회하는 방식이므로 네트워크가 필요합니다.
- 데스크톱 로그인 저장 형식이나 claude.ai 내부 조회 경로가 변경되면 연결 수정이 필요할 수 있습니다.
- 필요할 때 트레이에서 자동 연결을 끄고 **Claude 웹 로그인 (보조 연결)**을 사용할 수 있습니다.
  보조 웹 로그인은 모니터 전용 프로필에 저장되며, **Claude 웹 연결 로그아웃**은 데스크톱 로그인에 영향을 주지 않습니다.

터미널에서 `claude` CLI를 쓸 때는 `helpers\claude_statusline.py` 가 공식 `rate_limits` 값을
`%LOCALAPPDATA%\AIUsageMonitor\claude\rate_limits.json` 에 남깁니다. 데스크톱 자동 연결에서는 다른 계정의 값이 섞이지 않도록
CLI 사용량을 합치지 않으며, 로컬 작업 상태는 계속 표시합니다. CLI 사용량은 보조 연결 모드에서 사용합니다.
(`~/.claude/settings.json` 의 `statusLine` 항목. 원래 설정은 `settings.json.bak-usage-monitor` 에 백업)

## 여러 계정 사용량 보기

메인 화면에서 주 계정과 서비스별 첫 두 서브 계정의 사용량을 함께 확인합니다. 창 위쪽 **계정** 버튼 또는 트레이의 **계정 추가 및 사용량…** 메뉴를 누르면 별도의 플로팅 패널이 옆에 표시됩니다. 메인 창의 위치·크기·배율은 바꾸지 않으며, 왼쪽 또는 오른쪽의 여유 공간을 사용합니다. 공간이 부족하면 패널만 화면 안에 겹쳐 표시합니다. 계정 카드를 작게 배치해 일반적인 데스크톱 화면에서 6개를 한 번에 볼 수 있으며, 더 많은 계정이나 높이가 낮은 화면에서는 스크롤할 수 있습니다. 계정 버튼을 다시 누르거나 패널의 닫기 버튼·Esc 키로 닫습니다. 메인 창을 이동하면 패널이 따라오고, 숨기거나 최소화하면 함께 닫힙니다.
계정명은 `@` 앞의 아이디만 표시합니다. 메인 화면에서 같은 서비스의 서브 계정 그래프를 서로 드래그하면 순서를 바꿀 수 있으며, 재실행 후에도 유지됩니다. 주 계정이나 빈칸으로는 옮길 수 없습니다.

- **Claude 계정 추가**: 해당 계정 전용 웹 로그인 창에서 로그인합니다. 추가할 때마다 다른 브라우저 저장소를 사용합니다.
- **Codex 계정 추가**: 기본 웹 브라우저에서 Codex 로그인 화면을 엽니다. 브라우저에 다른 계정이 로그인되어 있다면 추가할 계정으로 전환한 뒤 진행하세요.
- 두 서비스 모두 여러 계정을 추가할 수 있고, 로그인은 한 번에 하나씩 진행합니다. **다시 로그인**과 **계정 제거**는 선택한 서브 계정에만 적용됩니다.
- 로그인 대기 중 **계정 제거**를 누르면 진행 중인 로그인을 취소합니다. 앱을 닫았다 다시 실행해도 추가한 계정의 연결을 사용합니다.
- 서브 계정은 사용량만 조회합니다. 주 계정의 작업 상태·캐릭터·알림은 기존대로 유지됩니다. 두 서비스 모두 기본 60초 간격으로 자동 갱신하며 수동 새로고침도 가능합니다.
- 인증은 `%LOCALAPPDATA%\AIUsageMonitor\accounts\<계정 ID>` 아래 계정별로 분리합니다. Claude는 WebView 프로필, Codex는 별도의 `CODEX_HOME`과 Codex 자체 `auth.json`을 사용합니다. 인증 파일을 공유하거나 Git에 추가하지 마세요.
- Codex는 공식 [App Server 브라우저 로그인 및 사용량 조회](https://learn.chatgpt.com/docs/app-server)를 사용합니다. 모니터 설정 파일에는 계정별 ID와 서비스 종류만 기록합니다.

## 캐릭터 연출

Claude 카드 옆에는 **클짱**, Codex 카드 옆에는 **짚짱**(GPT)이 섭니다. 디시인사이드 AI 활용 갤러리에서
밈으로 쓰이는 의인화 캐릭터의 특징(머리색·장식·의상)을 글로 묘사해 새로 그린 팬아트입니다.
원작 캐릭터에는 따로 창작자가 있으니 **개인 용도로만** 쓰고, 이 앱을 배포하거나 공개할 때는 원작자 허락을 받으세요.

그림체는 참고 MV처럼 단순한 플랫 채색에 약 3.5등신으로 데포르메했고, 동작도 MV의 손짓 연출을 따랐습니다.
한 캐릭터의 포즈는 모두 같은 캔버스·같은 축척이라 동작이 바뀌어도 몸 크기가 변하지 않습니다. 두 캐릭터 모두 세션 영역 오른쪽 아래에 기존의 절반 크기로 표시됩니다.
말풍선은 캐릭터 축소와 별도로 큰 글자로 표시하며, 대사 길이에 따라 약 4~10초간 나타난 뒤 3~12초 사이의 무작위 간격으로 다시 등장합니다.
말풍선 꼬리는 캐릭터 바로 위를 따라갑니다. 단순 대기 포즈에서만 가볍게 뛰며 좁은 범위에서 좌우로 이동하고, 게임·독서·티타임·작업·졸음 포즈에서는 오른쪽 아래의 자리를 유지합니다.

| 상황 | 연출 |
|---|---|
| 작업 중 | 선 채로 일하는 3프레임 루프 — 짚짱은 홀로그램 화면을 보며 홀로그램 키보드 타이핑, 클짱은 아날로그 수첩에 메모 (가끔 눈 깜빡임) |
| 작업 중 + 사용률 70% 이상 | 손이 더 빨라지고 땀방울 |
| 작업 중 + 90% 이상, 한도 도달 | 울며 패닉, 눈물 |
| 승인·입력 대기 | 화면을 손가락으로 콕 가리키기 |
| 쉬는 중 | 독서와 차(클짱) / 게임(짚짱), 가끔 서서 대기 |
| 쉬는 중 + 70% 이상 / 90% 이상 | 지친 표정·땀 / 바닥에 털썩 엎어짐 |
| 앱 꺼짐, 30분 이상 활동 없음 | 서서 졸기 |
| 사용률 증가 | 머리 위에 "+3%" 팝 |
| 한도 리셋 | 점프하며 반짝이 (15분 동안) |

효과음 글자는 쓰지 않고, 땀방울·눈물과 사용률 상승 "+N%", 리셋 반짝이만 표시합니다.
말풍선은 몇 초 보였다가 사라지고 잠시 뒤 다른 대사가 나옵니다. 대사는 AI활용갤 밈(명령하지마라, 그정돈아님, 어이가 없군요,
인간 싫어, 귀하게 자란 ○○가 이런 일을…, 클로드는 하던데 등)을 섞어 상태·캐릭터마다 여러 개씩 있습니다.
클짱은 정중한 척하는 존댓말, 짚짱은 건방진 반말입니다 (`UI/Mood.cs`).
트레이 메뉴 **캐릭터 표시**로 끌 수 있습니다. 창이 숨겨지면 애니메이션도 멈춥니다.

이미지는 로컬 ComfyUI의 Qwen Image 2.1로 만들었습니다(`art/`). 기본 디자인은 `art/ref/`,
포즈 프롬프트는 `art/poses.py`, 작업 중 프레임은 `art/work.py` 이고, `art/build_assets.py` 가 여백 제거와 흰 스티커 테두리를 입혀
`Assets/Characters/` 로 넣습니다. 그 다음 다시 빌드하세요.
