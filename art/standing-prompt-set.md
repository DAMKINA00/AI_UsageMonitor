# Desktop standing sprites

Built-in ImageGen edited one existing neutral character portrait at a time with a transparent background. The selected PNGs were resized to 420 pixels high for `Assets/Standing/`. The original generated PNGs remain in the Codex image output folder.

## Prompt set

Use the supplied neutral portrait as the character and style reference. Extend it to a complete standing SD desktop mascot. Match the hair, eyes, face, accessories, outline, and cel colors. Keep the head about 46 percent of the visible height, with a short body and legs. Both shoes must be fully visible and rest on the same baseline. Leave clear alpha around the complete figure. Use one character with no setting, text, or shadow.
